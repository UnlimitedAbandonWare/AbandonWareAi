# Demo1 Long Think Goal Composer

Use this skill when a pasted long-run goal needs to become narrow,
evidence-backed Safe Patch lanes before any source edit. The deliverable is a
compact goal contract and branch choice, not an architecture essay.

## Core Rule

Read the user's pasted or attached goal first, then verify the live Desktop root.
Current command output beats prompt claims, memory, and old monitor summaries.
If a row of evidence cannot be completed, write:

```text
evidence_needed: missing artifact / verify with exact command
```

## Operating Contract

1. Read the goal or attachment before searching source.
2. Confirm Desktop root, PatchDrop state, source-edit lease/preimage state,
   any real index/ref operation in progress, and active sourceSets.
3. Identify the target metric, observed current state, gap, suspected causal
   chain, active surface, sourceSet, and falsifying proof command.
4. Score only candidates backed by active source, active scripts, or current
   command output.
5. Pick the smallest decomposition mode that changes the next decision.
6. Convert Browser, Computer, Supabase, and Superpowers tags into separate
   evidence lanes, not broad edit authorization.
7. Return `no_patch_needed` when live source proves the requested behavior is
   already present.
