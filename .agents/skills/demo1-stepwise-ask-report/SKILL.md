# Demo1 Stepwise Ask Report

## When
- Scope about to grow past the current small step
- Ambiguity after web search
- Needs plugin/login/secret/DNS/cert/device action
- Irreversible or hard-to-roll-back change

## Do
1. Web-search (Exa when available) for facts.
2. Report in short bullets: known / unknown / options / risks / **plugins that may be required**.
3. Ask go/no-go or which option.
4. On approval, execute **only that step**, then report again.

## Do not
- Silent autograder sweeps
- Proceed on irreversible branches without an answer
- Say "mode"
