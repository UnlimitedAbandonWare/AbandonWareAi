Debug Events

DebugEventStore(링버퍼)에 쌓인 구조화 이벤트를 웹에서 확인합니다. (fail-soft 경로/컨텍스트 전파 누락/회복 로직 관찰용)

JSON API: /api/diagnostics/debug/events, /api/diagnostics/debug/fingerprints, /api/diagnostics/debug/events/stream (SSE), /api/diagnostics/local-llm/smoke-history, /api/diagnostics/debug/triadic-adjudication
