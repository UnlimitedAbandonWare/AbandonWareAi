- Project Root는 `C:\AbandonWare\demo-1\demo-1\src`이다.

- Google Gemini API 공식 정책상 `gemini-2.5-flash-lite`는 입력 $0.10/1M, 출력 $0.40/1M 수준의 극저가 모델이며, Google AI Studio 무료 티어(Rate limits 내 $0)로도 활용 가능하다.

- `main/resources/application.properties:35-36`에도 `gemini.curator.model=gemini-2.5-pro`, `gemini.batch.model=gemini-2.0-flash`로 구형/고비용 모델만 명시되어 있다.
