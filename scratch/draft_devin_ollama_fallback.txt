## 0. 한 줄 목표

  1) **4대 병목 감지 및 조기 탈출(Fast-Spillover) 트리거**:
     - 트리거 A (슬롯 포화): `LocalModelAdmission.tryAcquire` 실패 시 큐잉 없이 즉시 클라우드 API 우회 (`local_contended`).
     - 트리거 B (초기 토큰 지연 워터마크): 로컬 호출 후 TTFT가 2,500ms 초과 시 로컬 Abort 후 즉시 Zero-Token 클라우드 API 백업 모델로 전환.
     - 트리거 C (HTTP 503 / 큐 적체): Ollama 503 또는 Connection refused 시 로컬 재시도 0회로 클라우드 API 즉각 폴백.
     - 트리거 D (GPU 상태 이상): `gpu_incident` 플래그 활성화 또는 VRAM 임계치 도달 시 사전(Pre-dispatch) 단계에서 로컬 배제.
  2) **클라우드 API 폴백 우선순위 사다리(Fallback Ladder)**:
     - 1순위: ChatGPT OAuth (구독 포함량, 비용 0, 사용자 인증 세션 연동)
     - 2순위: Groq / Gemini (초저지연/저비용 클라우드 고속 엔진)
     - 3순위: OpenAI API / Anthropic (고품질 상용 엔진)
