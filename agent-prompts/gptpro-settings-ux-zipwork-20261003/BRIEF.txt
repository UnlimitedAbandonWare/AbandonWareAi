4. chat.js는 따로 탭 단위 sessionStorage 키 `chat.controlSettings`에 현재 값을 저장·복원합니다. 저장 층이 두 개라 저장값과 지금 적용값이 다를 수 있습니다.
5. 채팅 상단에 접히는 관리자 메뉴(Brain, Pipeline Status, RAG Ops, Vector, Models)와 Diagnostics가 있고, model-settings.html은 영어 라벨입니다.
6. 모델 선택 대화상자는 이미 main/resources/static/js/chat-model-picker.js에 있습니다(검색·즐겨찾기). 새로 만들지 말고 재사용하세요.
7. ZIP(core 프로필)에는 테스트 폴더(src/test)와 Gradle wrapper jar가 없습니다. 그래서 Java 테스트와 Gradle 빌드는 여기서 돌릴 수 없고 NOT_RUN입니다. WP2 화면 구조 재배치 (settings.html, settings-page.css)
- 3층: 기본(항상 보임) → 고급(details 접힘) → 개발자·진단(details 접힘). 역할별 모델과 실행 설정은 개발자 층으로, 관리자 페이지 링크(Brain, Pipeline Status, RAG Ops, Vector, Models)도 개발자 층에서 그대로 찾을 수 있게.
- 각 컨트롤 옆에 저장 범위 표시: "이번 대화만" / "이 브라우저 기본값" / "서버 설정(관리자)".

- 쉬운 한국어 이름 + 한 줄 설명 + 기본값에 "권장" 표시. FORCE_LIGHT 같은 값 이름은 고급 층에서만 괄호로.

- 저장값과 이 탭의 적용값이 다르면 배지로 표시(가능한 범위에서, 불가능하면 [가정]으로 이유).
- 초기화는 확인 한 번 거치기. 역할별 모델 revision 충돌 시 덮어쓰기 대신 "다시 불러오기" 안내 문구.
