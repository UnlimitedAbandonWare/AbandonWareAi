## 항목 (WP1 ~ WP4)

### WP1. 90일 마일스톤 로드맵 및 The Gap Matrix(사각지대 목록) 수립 (`docs/api-spec-catalog/00_ROADMAP_AND_GAP_MATRIX.md`)
- 90일(12주차 / Phase 1~4) 단계별 실행 로드맵 수립:
  * Phase 1 (Day 1~30): 사각지대 인벤토리 확정, 엣지케이스 매트릭스, 모의 재현 환경(Mock Testbed) 설계.
  * Phase 2 (Day 31~60): 트랙별 심층 실증, 네트워크 패킷 프레이밍 및 시퀀스 다이어그램 작성.
  * Phase 3 (Day 61~80): 프로덕션 레벨 클라이언트 방어 패턴(State Machine, 재시도/하트비트) 및 프록시 설정 레퍼런스.
  * Phase 4 (Day 81~90): Living API Spec 통합 패키징, OpenAPI 3.1 / AsyncAPI 3.0 확장 스펙, 최종 발행.
- The Gap Matrix: 규격명 | 공식 문서 유무 | 웹 검색 가용성 | 위험도(Critical/High) | 실무 엣지케이스 요약.

### WP2. Track 1 & 2: AI Agent/WebRTC 및 DPoP/OAuth 2.1 미문서화 규격서 (`docs/api-spec-catalog/01_AI_AGENT_PROTOCOLS.md`, `02_ZERO_TRUST_AUTH.md`)
- Track 1 (AI & Agent):
  * MCP: stdio 파이프 vs Streamable HTTP(SSE) 프레이밍 차이, JSON-RPC 2.0 `$cancellation` 및 구독 라이프사이클, 하트비트 스펙 부재 극복.
  * OpenAI Realtime (WebRTC): Ephemeral Token 1~2분 수명 사전 갱신(30초 전), ICE 재연결 시 세션 컨텍스트 재주입, Barge-in 시 오디오 버퍼 플러시, STUN/TURN 필수성.
  * Anthropic Messages Tool Use: 스트리밍 중 Partial JSON 파싱 및 네트워크 단절 시 도구 호출 상태 복구.
- Track 2 (Zero-Trust Auth):
  * RFC 9449 DPoP: `htu` claim 검증 시 쿼리/해시 제외 규칙, L7 프록시 `X-Forwarded-*` 불일치 방어.
  * `DPoP-Nonce` 헤더 챌린지 루프 및 Clock Skew(`iat`) 허용치 설계.
  * `jti` 유일성: 재시도 시에도 신규 키 서명 및 신규 `jti` 발급 필수성.
  * RFC 8693 Token Exchange에서의 DPoP 키 바인딩 영속성(Binding Persistence).

### WP3. Track 3 & 4: 스트리밍 전송 및 Rate Limiting/멱등성 장애 대응 규격서 (`docs/api-spec-catalog/03_STREAMING_TRANSPORT.md`, `04_RATELIMIT_IDEMPOTENCY.md`)
- Track 3 (Streaming & Transport):
  * SSE: Nginx/Cloudflare 버퍼링 방지(`X-Accel-Buffering: no`), HTTP/2 프록시 유휴 타임아웃 방지용 Comment Ping(`: keepalive\n\n`).
  * EventSource 자동 재연결 시 `Last-Event-ID` 누락 문제 및 서버 측 링 버퍼(Ring Buffer) 백프레셔 설계.
  * WebSocket / gRPC-Web: L7 유휴 연결 끊김 감지 하트비트, gRPC-Web `trailers-only` 응답 처리 엣지케이스.
- Track 4 (Rate Limiting & Idempotency):
  * 비표준 Rate Limit 헤더: IETF Draft `RateLimit-*` vs `X-RateLimit-*` vs 벤더 헤더 비교 및 정규화 파서.
  * `Retry-After` 헤더 HTTP-date vs seconds float 혼재 파싱, Full Jitter 지수 백오프 공식.
  * `Idempotency-Key`: 서버 In-Flight 상태 중복 요청 처리(`409 Conflict`), 캐시 TTL 만료 경쟁 상태 방어.

### WP4. 90일 카탈로그 인덱스 및 자체 유효성 검증기 (`docs/api-spec-catalog/README.md`, `scripts/validate_api_catalog.py`)
