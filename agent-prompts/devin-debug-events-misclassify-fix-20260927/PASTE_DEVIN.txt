### WP1 — 분류 축 분리 (SOURCE FIX, THE ONE)
목표: **원격 확정 rate limit** vs **로컬/추정**을 카테고리·evidence·confidence로 분리.
제안(기존 enum/문자열 최소 확장; 이름 고정 말고 동등 의미 OK):
- 원격 확정: HTTP **429** (또는 provider body code rate_limit_exceeded 등 **응답 근거**) → category `rate_limit`, evidence `http_429`|code, confidence **CONFIRMED**, httpStatus=429
- 로컬/추정: `RATE_LIMIT_COOLDOWN` / ModelSelection / transmit-guard / 메시지 휴리스틱만 → category **`local_throttle`** 또는 `preflight_reject` (또는 기존 `provider_error`+evidence=`rate_limit_suspected`), confidence **SUSPECTED**, httpStatus=0
- **금지:** httpStatus=0 인 추정을 UI/파이프라인에서 원격 `rate_limit`와 동일 DEGRADED 가중으로 취급
- 건드릴 후보:
  - `ApiFailureRecorder.recordFailureClass` (RATE_LIMIT_COOLDOWN 매핑)
  - 호출부: `ModelRuntimeHealthTracker` / `ConversateApiCueService` / gateway classifier 결과 전달부
  - `LlmGatewayFailureClassifier`: 메시지에 "429" 문자열만으로 RATE_LIMIT 확정하지 말 것(가능하면 status 우선)
