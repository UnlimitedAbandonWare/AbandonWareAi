## 5. Gaps / 아쉬운점 (순위 + 증거)

### G1 — 자가고아(self-orphaned) marker `index.lock`이 soft-auto로 안 풀림 (마찰 최대)
- `commit_selected`가 lock에 `conditional-local-git:<uuid>` marker를 **비어 있지 않은** 바이트로 씀. 실패 후 finally가 못 지우면 잔존.
- `clear_stale_lock`은 **0-byte만** archive → nonempty marker는 항상 `lock-nonempty` → `deferred=index-lock`.
- 증거: `data/agent-handoff/codex-autonomy/devin-safe-git-commit-update-0927-b6f0e3c8/journal.json` (user-approved move-aside, marker `conditional-local-git:fdf7370a`, 54B, writers=0); 동 폴더 `index.lock.bak-20260927*`.
- soft-auto 문서(`demo1-vibe-git-auto-continue`)는 “0-byte + age”만 말함 → **자기 marker 회수 규칙 공백**.

### G2 — `selected-*-failed`가 불투명 (에이전트 UX 공백)
- `commit_selected`가 `git_staged_guard` stdout JSON/`ok:false` reason을 버리고 `selected-staged-scan-failed`만 반환.
- 예외도 `selected-commit-failed` + `errorType`만 — 원인 메시지/가드 reason 없음.
- 증거: 동 handoff `final.json` `failedBatches` 6건 전부 위 두 reason; `progress.json` `failed:6`. 배치 경로에 `__pycache__/*.pyc` 포함돼도 실패 사유가 안 보임.

### G3 — `__pycache__` / `*.pyc` 등이 `path_forbidden` 밖
- `path_forbidden`은 secrets/env/key/lmsdb/.git 중심. bytecode·캐시 디렉 미차단.
- 증거: failed batch `scripts` 경로 샘플에 `scripts/__pycache__/*.cpython-311.pyc` 포함 (`final.json`).

### G4 — stale-lock TTL / 스테이징 모드 이중 기본값 (모호성)
- 오케스트레이터 `--stale-lock-days` 기본 **0.25(6h)** vs `lock --days` 기본 **1.0** — 같은 soft-auto 스킬에 둘 다 적혀 경로에 따라 동작 다름.
- 저수준 `commit` 무플래그 = exact-match; 오케스트레이터 기본 = preserve-foreign. 저수준만 부르면 foreign-or-mismatched-staging에 자주 막힘.

### G5 — blast-radius=40 경계에서 조기 안내 부족 + doctor 미연결
- 실패한 main/java·scripts·src/test 배치가 경로 40개 = cap. 불투명 실패로 떨어져 “왜/어떻게 쪼갤지” UX 없음.
- `git_doctor.py`의 `nextOwner` / foreign split이 vibe deferred 경로에 자동 연결 안 됨(under-used).

## 6. THE ONE / Top work items (가장 얇은 시임) + Acceptance

**우선순위: W1 → W2 → (여유 시) W3.** 병렬 스택 ❌.

### W1 — Self-orphaned marker lock soft-reclaim (extend `clear_stale_lock` + orchestrator)
- **변경 위치:** `scripts/conditional_local_git.py` (`clear_stale_lock` / lock 평가), `scripts/agent_git_vibe_commit.py` (`assess_lock`), skill `demo1-vibe-git-auto-continue` + `demo1-conditional-local-git` 한두 문장, 테스트 추가.
- **동작:** lock 내용이 `conditional-local-git:` prefix marker이고, 확인된 `git.exe` writer 없음, shared `index` 해시 불변이면 → **0-byte가 아니어도** backup_dir로 **move aside**(삭제 금지). 외래/비어있지 않은 비-marker lock은 기존대로 `preserved`.
- **Acceptance:**
  - [ ] fixture: marker lock + writers=0 + index unchanged → `action: cleared` (또는 동등) + bak 파일 존재 + index.lock 제거.
  - [ ] fixture: 임의 nonempty lock / writer 있음 / index 변경 → `preserved` + 이유 코드, **삭제안함**.
  - [ ] `agent_git_vibe_commit --dry-run`이 위 경우 `would-clear`(또는 동등)로 계획에 표시.
  - [ ] 기존 0-byte stale 규칙 회귀 유지.
  - [ ] journal 가능 시 `AUTO:self-orphaned-lock-cleared=…` (task-id 있을 때).

### W2 — Opaque failure → 진단 페이로드 (extend `commit_selected` / vibe JSON)
- **변경 위치:** `commit_selected`의 `selected-staged-scan-failed` / `selected-commit-failed` 반환; 오케스트레이터 `deferred` detail 전달; `test_conditional_local_git.py`.
- **동작:** 가드 stdout JSON의 `reason`/`findings` 요약(내용·시크릿 값 **절대 미인쇄**), 예외 `errorType`+짧은 safe message, 가능하면 stderr redacted snippet. 상위 reason 코드는 유지(호환).
- **Acceptance:**
  - [ ] 가드가 `ok:false`일 때 응답에 `scanReason`(또는 동등) 필드가 생기고, 테스트가 단언.
  - [ ] RuntimeError/timeout 경로에 `errorType` + safe detail; 시크릿 패턴 문자열이 stdout JSON에 없음.
  - [ ] 기존 exit code 의미(2/3/4) 유지.

### W3 — `path_forbidden`에 빌드잡 경로 + blast early-signal (작은 연장)
- **변경:** `path_forbidden`에 `__pycache__/`, `*.pyc`, (선택) `*.class` under `build/` 등 **이미 정책 정신에 맞는** 잡경로 거부; `agent_git_vibe_commit` dry-run/deferred에 `candidatePathCount`/`maxPaths`/`remainingCapacity` 명시(이미 일부 있음 → 문서·early deferred 강화).
- **Acceptance:**
  - [ ] `--path scripts/__pycache__/x.pyc` → `forbidden-path` / deferred, 커밋 시도 전 거절.
  - [ ] paths>40 → `blast-radius-paths`가 opaque selected-*-failed보다 **먼저** 명확히(이미 commit_selected 앞단 있음 — vibe/드라이버가 우회하지 않게 테스트·스킬 한 줄).
  - [ ] TTL 기본값: orchestrator와 `lock --days`를 **하나의 SSOT 상수**로 맞추거나, 스킬/AGENTS에 “에이전트는 orchestration 기본만 쓴다”고 단정(코드 상수 정렬 권장).
