```
1. 플레이트 선택: W1_AUTH(공식 정책·가격) / W2_FRESH(최신) / W3_TECH(라이브러리·에러) / W4_LOCAL(로컬 작업 사실 확인) / W9_LITE(단순) / WB_BRAVE("깊게").
2. 질문을 하위 질문 2~3개로 쪼개고, 하위 질문마다 한국어·영어·site:공식도메인 질의를 1~2개 만든다. 검색은 W9 1~2회, 보통 3~5회, WB 최대 10회.
3. 결과를 합쳐 순위를 매긴다: 여러 질의에서 겹친 것, 공식(T1) > 공식 GitHub·표준(T2) > 언론(T3) > 블로그(T4), 최신 우선(오래된 근거는 STALE 표시).
4. 상위 2~3개(WB 5개)는 본문을 열어 주장이 실제로 있는지 확인한다. 복제 기사는 하나로 묶는다. 핵심 주장은 독립 출처 2개 이상, 또는 공식 1개.
5. 근거가 적거나·권위가 낮거나·서로 다르면 원인을 적고 구체적으로 다시 검색한다(최대 2라운드). 그래도 안 되면 "확인 못 함"이라고 쓴다.
6. 답 순서: 결론 → 근거([n] 번호) → 출처끼리 다른 점 → 출처:(제목·날짜·T등급·본문확인) → `웹: 플레이트 · 검색 n회 · 본문확인 n · 출처 n(T1 n) · 모순 유/무`.

```

## DV3 — 결정적 도구 `scripts/agy_web_fuse.py` (약한 모델 보조)
- 입력: stdin 또는 `--in` 파일. JSON 형식은 `{"question":"…","plate":"W3_TECH","items":[{"url","title","date"(선택, ISO),"snippet","query_id","rank","body_checked"(bool)}]}`.
- 처리:
  1. URL 정규화(스킴·www·추적 파라미터 `utm_*`·`#` 제거) 후 중복을 묶는다.
  2. 제목과 요약 3-gram 유사도 ≥0.6이면 "복제 그룹"으로 묶는다.
  3. 질의별 rank로 RRF(k=60)를 계산한다.
  4. `authority_tiers.json`의 등급 가중치를 곱한다.
  5. 플레이트가 W2·W3면 날짜 가산을 하고, 12개월이 넘으면 `STALE`로 표시한다.
  6. 본문을 확인한 항목에 가산한다.
  7. 최종 점수순으로 정렬한다.
  8. 복제 그룹에서는 대표 1개만 남긴다.
  9. 상위 N(기본 5)을 인용 후보로 낸다.
  10. 게이트를 판정한다: 출처 수(플레이트별 최소), T1 유무, 독립 출처 2개 이상, `SPARSE`/`LOW_AUTHORITY`/`CONFLICT_SUSPECT`(같은 하위 질문에 날짜·숫자가 다른 요약이 섞이면) 플래그.
- 출력: JSON `{"ranked":[…{"url","tier","score","stale","dup_group"}],"cite":[…],"gate":{"pass":bool,"flags":[…],"next_query_hints":[…]},"breadcrumb":"웹: … "}`. `--format md`로 사람이 읽는 표도 낸다.
- 표준 라이브러리만 쓰고, 네트워크와 파일 쓰기는 0이다. 1,000개 항목도 1초 안에 끝나야 한다.
- `next_query_hints`는 플래그별 Critic 재검색 문장이다. 예: LOW_AUTHORITY → "`site:<T1 후보 도메인>` + 핵심 앵커"

## DV4 — Stop hook 인용 게이트 (CitationGate를 강제)
- `scripts/agy_websearch_hook.py`에 `--event stop` 모드를 **추가**한다. 기존 PreInvocation 동작은 그대로 둔다.
- 판단 순서(transcript 구조는 선행 지시서 DV1에서 확인한 것을 쓴다):
  1. 이번 턴에 웹서치 단계가 0이면 → `{}`(선행 hook이 담당).
  2. 마지막 어시스턴트 답에 `출처:` 줄과 `웹:` 브레드크럼이 둘 다 있으면 → `{}`.
  3. 둘 중 하나라도 빠졌고 이번 턴에 아직 continue를 보낸 적이 없으면 → `{"decision":"continue","reason":"[AWX] 답 끝에 출처:(제목·날짜·T등급) 목록과 '웹: 플레이트 · 검색 n회 · 출처 n' 한 줄을 붙여 다시 마무리하세요."}`.
  4. 같은 턴에 이미 1회 보냈으면 → `{}`(**회로 차단기: 턴당 최대 1회**, 무한 루프 금지). 상태는 `%USERPROFILE%\.gemini\config\hooks\state\<conversationId>.json`에 마지막 턴 식별자만 저장하고, 7일 지난 파일은 지운다.
  5. 어떤 오류든 → `{}`, exit 0(fail-open). 300ms 이내.
- `[no-web]` 턴은 전부 `{}`다.
- hooks.json 키 `awx-uaw-citation-gate`에 `Stop` 항목을 넣는다. 명령은 선행과 같은 python 절대 경로 + `-B` + 배포 사본 + `--event stop`, timeout 5다.
- 설치 스크립트에 `--profile uaw`(기본은 `base`)를 **추가**한다. `--apply --profile uaw`는 base를 보장한 뒤 UAW 블록, Stop hook, 스킬 사본을 넣는다. `--uninstall --profile uaw`는 UAW 부분만 제거하고 base는 남긴다. `--check`는 층을 5개로 늘린다: RULE, HOOK_PRE, ALLOW, UAW_RULE, HOOK_STOP, 그리고 SKILL 상태.
