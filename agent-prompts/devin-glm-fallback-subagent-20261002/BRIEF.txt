  L2 assist_glm_fallback 서브에이전트(spawn).
  L3 기존 assist_* 또는 기본 탐색 에이전트. L2 spawn 자체가 실패했을 때만 쓴다.

  · HTTP 400 "not supported when using Codex with a ChatGPT account" → NATIVE_UNSUPPORTED → L2
  · MCP BLOCKED_EXTERNAL / MCP 미설정 / MCP 서버 기동 실패 → MCP_UNAVAILABLE → L2
  · 401/403 → AUTH_OR_PLAN(Vercel Hobby 403 plan_gate 포함) → L2, 재시도 없음
  · 429 → RATE_LIMITED → L2, 재시도 없음
  · 90초 안에 응답 없음 → TIMEOUT → L2
  · 빈 응답, 형식 위반, delivery marker 없음 → BAD_OUTPUT → L2
  · L2 spawn 오류(max_threads 초과 등) → L3. L3 도 실패하면 L4.

  · 같은 단계 재시도 0회

  · 폴백 결과는 GLM 결과와 같은 자리에 쓴다. 최종 판단과 수정은 항상 Codex 가 한다.
  · 보고에는 GLM_LANE=L1|L2|L3|L4 와 REASON 을 남긴다.
- 이전에 고친 저장소 스킬 3개의 문장도 이 순서를 가리키게 맞춘다(최소 수정).
