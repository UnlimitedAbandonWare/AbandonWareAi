## 2. 라이브 트리에서 이미 확인된 사실 (Grok Bot, 2026-10-03 08:14 KST, HEAD 4150b282)
1. 설정 화면은 templates/settings.html 한 장이고 카드 3개입니다.
   - "이 브라우저 기본값"(#browser-settings): 모델, 모델 사용 방식(preferred/strict/auto), 검색(OFF/AUTO/FORCE_LIGHT/FORCE_DEEP), RAG.
   - "역할별 모델"(#role-routing): 서버 프로필, 기본 OFF, 미리보기 → 저장(settings-routing.js, revision 충돌 검사 있음).
   - "실행 설정"(#execution-settings): 읽기 전용(settings-page.js 의 publicKeys: TEMPERATURE, TOP_P, … chat.ragAnswerPolicy).
2. 브라우저 기본값은 localStorage 키 `awx.settings.v1.preferences` 에 저장됩니다(chat-settings-bridge.js STORAGE_KEY). 기본값은 DEFAULTS = { modelSelectionMode:'preferred', searchMode:'OFF', useRag:false }.
3. 같은 브리지가 채팅 화면(chat-ui.html 에서도 로드)에도 붙어 있어서, 채팅에서 모델·검색·RAG를 바꾸면 change 이벤트에서 그 값을 같은 localStorage 키에 다시 씁니다(chat-settings-bridge.js, controls change → writeSettings). 즉 "이번 대화에서만 바꾼 값"이 "다음 대화 기본값"이 됩니다. GPT Pro 이전 답변의 판단과 일치합니다.
4. chat.js 는 별도로 탭 단위 sessionStorage 키 `chat.controlSettings` 에 현재 컨트롤 값을 저장·복원합니다. 저장 층이 두 개라서 "저장값"과 "지금 적용값"이 다를 수 있습니다.
5. 채팅 상단에는 접히는 관리자 메뉴(details.admin-tools: Brain, Pipeline Status, RAG Ops, Vector, Models)와 Diagnostics 접힘 영역이 있습니다. model-settings.html 은 영어 라벨(Default Model Settings 등)입니다.
6. 관련 테스트가 이미 있습니다: SessionSettingsPrecedenceTest, ChatRequestSettingsMergerTest, SettingsExposurePolicyTest, SettingsControllerPublicProjectionTest, RoutingSettingsControllerTest 등. 새 테스트를 만들기 전에 이것부터 재사용하세요.
7. 모델 고르기는 이미 chat-model-picker.js(검색·즐겨찾기 대화상자)가 있습니다. 새 선택기를 만들지 말고 재사용하세요.

## 4. 설정 화면 설계 원칙
1. 저장 범위를 3단으로 나누고 모든 컨트롤 옆에 표시: "이번 대화만" / "이 브라우저 기본값" / "서버 설정(관리자)". 채팅에서 바꾼 값은 기본으로 "이번 대화만"이고, 기본값으로 올리려면 사용자가 "앞으로도 사용"을 눌러야 합니다.
2. 3층 구조: 기본 → 고급(접힘) → 개발자·진단(접힘). 기존 기능은 지우지 말고 위치만 옮기거나 접으세요.
3. 쉬운 한국어 이름 + 한 줄 설명 + 기본값에 "권장" 표시. FORCE_LIGHT 같은 영문 값은 고급 영역에서만 괄호로 보여 줍니다.
4. 입력 방식: 선택지 3~4개 이하는 라디오/세그먼트, 켜기·끄기는 스위치, 모델은 기존 picker 재사용.
5. 오류 예방: 저장값과 지금 적용값이 다르면 배지로 표시, revision 충돌 시 덮어쓰지 말고 "다시 불러오기" 안내, 초기화는 확인 한 번.
6. 접근성: label 연결, 설명은 aria-describedby, 상태 메시지는 aria-live, 키보드만으로 전부 조작, 색만으로 상태를 구분하지 않기, 포커스 표시 유지.
7. 개발자 모드 유지: admin-tools 메뉴, model-settings, 역할별 모델(기본 OFF), Diagnostics는 그대로 둡니다. PROTO_OPEN(로그인 없이 열린 개발 모드)은 유지하며, 잠금·권한 강화 제안은 하지 말고 필요하면 HOLD에만 적으세요.
8. 문구가 깨져 보이면(한글 인코딩) 파일 인코딩 문제일 수 있으니 [확인 필요]로 적고 UTF-8 유지만 요구하세요.
