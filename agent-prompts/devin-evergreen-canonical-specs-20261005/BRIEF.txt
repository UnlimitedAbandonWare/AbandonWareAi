### WP2. W3C/WHATWG Server-Sent Events (SSE) 불변 규격 (`docs/references/canonical-specs/W3C_SERVER_SENT_EVENTS_SPEC.md`)
- 경로: `docs/references/canonical-specs/W3C_SERVER_SENT_EVENTS_SPEC.md`
- frontmatter: `ttlDays: 365`, `cadence: evergreen`, `stability: high`, `canonicalSources: ["https://html.spec.whatwg.org/multipage/server-sent-events.html", "https://www.w3.org/TR/eventsource/"]`
- 내용:
  - MIME: `Content-Type: text/event-stream;charset=UTF-8`
  - 메시지 프레이밍: `\n\n` 더블 개행 종료, `:` 주석(keep-alive), 필드(`data:`, `event:`, `id:`, `retry:`)
  - 전송 제어: `Transfer-Encoding: chunked`, `Cache-Control: no-cache, no-transform`, `X-Accel-Buffering: no` (Nginx/Reverse Proxy 즉시 플러시).

### WP3. Cormack 2009 Reciprocal Rank Fusion (RRF) 규격 (`docs/references/canonical-specs/RECIPROCAL_RANK_FUSION_RRF_SPEC.md`)
- 경로: `docs/references/canonical-specs/RECIPROCAL_RANK_FUSION_RRF_SPEC.md`
- frontmatter: `ttlDays: 365`, `cadence: evergreen`, `stability: high`, `canonicalSources: ["https://doi.org/10.1145/1571941.1572114", "Gordon V. Cormack et al. SIGIR '09"]`
- 내용:
  - 표준 공식: $RRFscore(d \in D) = \sum_{r \in R} \frac{1}{k + r(d)}$, 논문 불변 상수 $k = 60$
  - 가중 공식: $Weighted\_RRFscore(d) = \sum_{r \in R} w_r \times \frac{1}{k + r(d)}$
  - demo-1 규칙: 1-based 순위, 미등재 랭커 0점 처리, `(sourceId, sourceRevision)` SHA-256 고유키 결합.

### WP4. H2 Concurrency & LLM Sampling 규격 (`H2_DATABASE_LOCKING_SPEC.md`, `LLM_SAMPLING_PARAMETERS_SPEC.md`)
- 파일 1: `docs/references/canonical-specs/H2_DATABASE_LOCKING_SPEC.md`
  - `FILE_LOCK` 옵션(FILE 워치독, SOCKET 소켓 락, FS 네이티브 락)
  - `AUTO_SERVER=TRUE` (Automatic Mixed Mode: 첫 프로세스 임베디드+백그라운드 TCP 서버 구동, 후속 프로세스 자동 TCP 접속)
  - lmsdb exit code 3 회수 가이드 및 `.lock.db` 정리 절차
- 파일 2: `docs/references/canonical-specs/LLM_SAMPLING_PARAMETERS_SPEC.md`
  - Temperature: $P(x_i) = \frac{\exp(z_i / T)}{\sum_j \exp(z_j / T)}$, $T=0.0$(Greedy/RAG 표준), 도메인 [0.0, 2.0]
  - Top-P: Nucleus sampling 누적 확률 질량 (0.0, 1.0]
  - Seed: 결정론적 생성 보장.
