## 1. 설정 인벤토리와 소스 근거

### 1.1 조사 범위와 신뢰 수준

입력 SHA-256: `d94c087f8d89eb2a8f14206c273b49ca82dbe3178cae464e483df8ecb39143ea`. ZIP 안의 실제 파일은 **2,394개**, Java는 **2,178개**다. 파일·크기·해시 전체 목록은 `audit/archive-manifest.json`에 있다. 설정·라우트·저장소 관련 구조 검색은 **2,369개 파일**에서 수행했다. 검색 결과의 파일별 행 번호는 `audit/structural-scan.json`에 남겼다. 요청에서 제외한 스튜디오 9개 파일과 바이너리·vendor·일부 기타 형식 등 25개는 이 구조 검색 대상에서 제외했다.

“전체 소스 분석”은 전체 입력의 구조·참조 후보를 확인하고, 아래 설정 관련 실제 호출 경로를 심층 추적한 뜻이다. 관련 없는 모든 Java 함수의 의미·성능·보안 결함까지 전수 검증한 것으로 확대 해석하면 안 된다. 스튜디오 UI는 설계·구현의 근거로 사용하지 않았다.

압축 루트는 `main/`이다. 아래 경로의 `resources/...`는 압축의 `main/resources/...`, `java/...`는 `main/java/...`를 뜻한다. 배포 패키지의 `src/main/...` 경로는 일반적인 Gradle 레이아웃에 맞춘 **적용 경로 초안**이며, Codex는 실제 checkout의 sourceSets를 먼저 확인해야 한다.

인벤토리는 주력 채팅, 요청된 공통 설정 API, 레거시 모델 설정, Display focus/relay/lens 및 그에 연결된 관측 저장값을 포함한 **108행**이다. 관리업무 CRUD·채팅 본문·파일 업로드·모든 환경변수를 새 설정으로 승격하지 않는다. 내부 실행 상태와 사용자 설정이 아닌 항목은 표에서 구별했다. 범위 밖 `@Value` 필드를 “사용자 설정 전체”라고 주장하지 않는다.

### 1.3 설정 인벤토리 표

각 행은 `파일명:행` 근거를 갖는다. 표에는 긴 경로를 줄여 파일명만 보이며 **전체 상대 경로와 복수 근거는 `settings-inventory.csv` / `audit/inventory.json`에 그대로 수록**했다. 동명이인 파일의 소속은 그룹 설명과 CSV 전체 경로로 확인한다. 신규 key/동작은 근거 없는 기존 기능으로 쓰지 않고 “제안” 또는 신규 설계로 표시한다.

공통 서버 값은 ConfigurationSetting을 재사용한다. Display는 사용자가 별도로 지정한 **기존 assist API가 이미 쓰는 기존 저장 방식**을 보존한다. Focus를 ConfigurationSetting으로 옮기거나 Lens를 새 DB 테이블에 저장하는 변경은 하지 않는다.

## 2. 화면 설계와 상호작용 규칙

### 2.1 선택한 구조

실현 가능한 안은 세 가지다. (A) 브라우저 기본값 4개만 옮기는 최소 페이지는 위험이 작지만 서버 설정이 계속 분산된다. (B) 브라우저 4개와 기존 API에서 안전하게 편집 가능한 공통 서버 값 6개를 분리하는 방식은 현 제약을 지키면서 가장 많은 실제 효용을 제공한다. (C) 모든 제안 기능을 편집 가능하게 만드는 방식은 채팅의 추가 소비자, 공개 경로 보안 변경, 프롬프트 API 계약, Display producer 인계까지 필요하다. **이번 초안은 B를 선택하고 C의 막힌 부분을 잠금·제안으로 남긴다.**

기존 `chat-style.css:1–25`의 밝은 page/surface, 녹색 accent, ink/muted, radius 토큰과 시스템 폰트 스택을 재사용한다. 기존 폰트 파일·CDN은 추가하지 않는다. 새 스타일은 `.settings-app` 아래로 한정하고 주력 채팅 스타일을 수정하지 않는다. `chat-ui.html`에 CSS 변수가 직접 있다고 가정하지 않고 실제 CSS 파일을 근거로 했다.

### 2.4 저장·적용·실패·초기화 규칙

**브라우저 저장은 명시값만 저장한다.** 물리 key는 `awx.settings.v1.preferences` 하나이며 `{"version":1,"values":{"searchMode":"OFF","useRag":false}}`처럼 명시한 값만 넣는다. 키가 없으면 기존 동작을 유지한다. 설명용 mergeDefaults 결과를 로드 시 저장하면 기존 사용자 설정을 덮게 되므로 그렇게 하지 않는다. RAG OFF는 false로 보존하며 `value || default` 같은 truthiness 병합을 사용하지 않는다.

입력의 change에서 한 번 저장하고 같은 문서 UI는 직접 갱신한다. localStorage 접근이 막히거나 quota 오류가 나면 마지막 확인 UI로 되돌리고 실패를 알린다. 다른 탭의 storage 이벤트는 기본값이 바뀌었다는 신호일 뿐 현재 대화 변경 명령이 아니다. storage 이벤트는 변경한 문서 자신에게 발생하지 않는다는 브라우저 계약도 반영했다 [W1,W2].

**적용 우선순위는 장면별로 구분한다.** 복원·활성 세션이면 chat.js의 기존 설정 복원 결과가 우선이며 브리지는 손대지 않는다. 완전히 새 대화에서는 신규 브라우저 명시값이 해당 네 필드에만 우선한다. 명시되지 않은 필드는 기존 sessionStorage/템플릿 로직을 그대로 따른다. 그 다음 사용자가 직접 선택하면 사용자의 값이 우선이다. 모든 브라우저 기본값을 주력 화면에서 양방향 자동 동기화하지 않는다.

네 값을 먼저 할당하고 필요한 컨트롤에 change를 발행한다. dispatchEvent 리스너는 동기 실행되므로 여러 값을 먼저 배치해야 핸들러가 중간 상태를 읽지 않는다 [W3]. 모델 카탈로그가 늦으면 기존 select의 사용 가능한 option을 최대 8초 관찰한다. 강제로 사용 가능 option을 만들지 않고, 선택 불가/누락 모델은 현재 선택을 보존한다. 타임아웃은 UI가 멈추는 대기가 아니라 observer 정리 기한이다.

**서버 저장은 항목별 단일 키 POST → GET 확인이다.** 한 키만 보내므로 무관한 설정을 덮어쓸 가능성을 줄인다. 입력 change 시 숫자 범위/enum 검증 후 저장 중 필드셋을 잠가 같은 페이지의 중첩 저장을 막는다. GET의 관리자 여부는 200에서 추정하지 않고 서버가 읽은 기존 Authentication/guard 판독을 사용한다. 이 판독은 화면 표시용이고 API는 여전히 기존 guard가 최종 결정한다.

POST 200만으로 “저장됨”을 표시하지 않는다. GET 값이 일치해야 확인 상태다. 요청이 timeout/잘못된 응답으로 끝나면 실제 서버 반영 여부가 불명확하므로 보상 POST나 자동 재시도 대신 한 번 재조회한다. 재조회도 실패하면 마지막 확인값을 보여 주되 **“저장 결과 불명”**과 잠금을 표시한다. “UI를 되돌렸다”와 “서버 저장을 취소했다”는 다른 주장이다.

권한 오류 401/403은 편집 잠금, 404/503·네트워크·HTML 리다이렉트는 사용 불가로 처리한다. 잘못된 숫자·enum은 API에 보내지 않는다. import는 UTF-8 16 KiB, 버전 1, 네 키의 정확한 타입/enum, 모델 ID 형식을 검증하고 사용자의 교체 확인 후 한 번에 쓴다. 알 수 없는 키·prototype 키·명백한 credential 모양 모델 값은 거부한다. 임의 객체를 Object.assign으로 전역 설정에 합치지 않는다.

초안의 로컬 쓰기는 저장 키 하나의 동기 setItem이며 다중 탭의 read-modify-write 전체를 잠그는 트랜잭션은 아니다. 동시에 두 탭이 저장하면 마지막 쓰기가 우선할 수 있다. 기존 서버 공통 API도 version/ETag가 없어 여러 관리자 간 완전한 충돌 방지를 보장하지 않는다. 단일 키 쓰기와 readback은 위험 감소이지 동시성 보장의 대체물이 아니다.

### 2.5 Display의 별도 완료 조건

`display-conversate.js:30–37,81–90`은 clientId와 연결 세션을 기존 클라이언트의 런타임에 유지한다. 새 페이지에서 다른 clientId를 만들거나 기존 연결 링크의 토큰을 가져와 복제하지 않는다. 실제 수음 탭을 떠나면 수음 자체가 중단될 수도 있어 페이지 간 인계 생명주기도 먼저 정해야 한다. 이 때문에 기본 HTML은 `display-settings-api.js`를 로드하지 않는다.

후속 인계가 준비되면 어댑터에 현재 producer가 검증된 connection을 메모리로 전달한다. Focus는 read로 얻은 최신 settingsVersion 및 전체 설정을 함께 보내고 409에는 새 값을 재확인한다. 레거시 optional block을 무조건 defaults로 덮지 않는다. 렌즈 patch의 0=OFF/상속 의미와 ms 단위를 보존한다. 반환 View의 카드·전사·링크 정보는 버리고 설정 부분만 추출한다.

또한 기존 Display UI는 `app.js:200–215`에서 Lens 설정을 `awx.display.settings.<channel>.lensDisplay`에 복제한다. 서버만 초기화하면 기존 생산자 UI가 이전 브라우저 값을 다시 적용할 수 있다. 인계 작업은 기존 저장/재적용 경로도 함께 확인해야 하며, 신규 namespace로 몰래 복제하거나 소유자·채널을 모른 채 지우면 안 된다. Focus DB 저장, Relay RAM, Lens RAM+기존 UI 복제는 서로 다른 지속성 계약이다.

### 2.6 기존 동작 변경 — 명시적 목록

1. 메인 헤더에 같은 탭 `/settings` 링크와 bridge script가 추가된다.
2. 신규 namespace에 명시값이 있는 경우만 완전히 새 대화의 네 컨트롤 기본값이 달라진다. 기존 “새 대화”가 직전 컨트롤을 그대로 물려받던 경로에는 신규 기본값이 우선할 수 있다. 기존 세션 복원에는 적용하지 않는다.
3. 이번 초안이 구독하는 기존 `brain-state:session`의 빈 detail 신호를 통해 새 대화에도 적용한다. 해당 이벤트를 수정하거나 chat.js 내부 함수에 접근하지 않는다. smoke/proof URL에서는 적용하지 않는다.
4. 주력 화면의 직접 변경은 기존 chat.controlSettings에만 저장된다. 그것을 신규 브라우저 영구 기본값으로 자동 승격하지 않는다.
5. 관리자 페이지에서 실제 저장한 공통 서버 값은 기존 SettingsService 및 ChatRequestSettingsMerger 경로로 다음 요청부터 영향을 줄 수 있다. 요청값과 모델별 sanitize가 우선하므로 “항상 동일한 최종 temperature”를 보장하지 않는다.

메인 `.response-settings` 제거, 레거시 전략 주입, 복원 세션 일괄 덮어쓰기, chat.js 편집, DB 마이그레이션, 권한 변경은 목록에 없으며 금지다.

      const raw = String(value).trim();
      if (!/^[+-]?(?:\d+\.?\d*|\.\d+)(?:[eE][+-]?\d+)?$/.test(raw)) throw Error('invalid_number');
      const n = Number(raw);
      if (!Number.isFinite(n) || n < ranges[key][0] || n > ranges[key][1]) throw Error('invalid_number');
      return String(n);
    }
    if (!Object.hasOwn(serverEnums, key) || !serverEnums[key].includes(value)) throw Error('invalid_enum');
    return value;
  }

    if (!data || typeof data !== 'object' || Array.isArray(data)) throw Error('invalid_server_response');
    const clean = {};

    for (const key of Object.keys(ranges)) clean[key] = serverValue(key, data[key]);
    for (const key of Object.keys(serverEnums)) {
      if (Object.hasOwn(data, key)) clean[key] = serverValue(key, data[key]);

  }

    for (const field of serverFields) field.value = confirmedServer[field.dataset.serverKey] ?? '';

    syncServerLock();
    sayServer('서버 저장 및 재조회 중', false);
    try {
      await jsonRequest('/api/settings', 'POST', { [key]: expected });
      const after = safeServerSnapshot(await jsonRequest('/api/settings'));
      confirmedServer = after;
      paintServer();
      sayServer(after[key] === expected ? '서버 저장값을 재조회로 확인했습니다.' :
        '요청값과 서버값이 다릅니다. 서버에서 확인된 값으로 표시했습니다.');
    } catch (error) {
      if (isDenied(error)) {
        serverReady = false;
        paintServer();
        sayServer('권한이 확인되지 않아 잠갔습니다. 저장 성공으로 처리하지 않았습니다.');
      } else {
        // Timeout/invalid response may occur after commit. Re-read once; never compensate or retry POST.
        try {
          confirmedServer = safeServerSnapshot(await jsonRequest('/api/settings'));
          paintServer();
          sayServer(confirmedServer[key] === expected ? '서버 재조회로 현재 값을 확인했습니다.' :
            '변경값을 확인하지 못해 서버에서 읽은 값으로 복원했습니다.');
        } catch {
          serverReady = false;
          paintServer();
          sayServer('저장 결과 불명 · 마지막 확인값만 표시합니다. 서버값 다시 읽기가 필요합니다.');
        }
      }
    } finally { serverBusy = false; syncServerLock(); }
  }

  byId('reload-server')?.addEventListener('click', loadServer);

      if (!section.hidden) count += 1;

      if (!query && button.dataset.category === category) button.setAttribute('aria-current', 'page');
      else button.removeAttribute('aria-current');

  'use strict';
  const STORAGE_KEY = 'awx.settings.v1.preferences';
  const MAX_BYTES = 16384;
  const KEYS = Object.freeze(['model', 'modelSelectionMode', 'searchMode', 'useRag']);
  // Explanatory template fallbacks. Never persist this merged object on page load.
  const DEFAULTS = Object.freeze({ modelSelectionMode: 'preferred', searchMode: 'OFF', useRag: false });
  const IDS = Object.freeze({ model: 'modelSelect', modelSelectionMode: 'modelSelectionMode',
    searchMode: 'searchModeSelect', useRag: 'useRagToggle' });

  function isRecord(value) {
    if (!value || typeof value !== 'object' || Array.isArray(value)) return false;
    const proto = Object.getPrototypeOf(value);
    return proto === Object.prototype || proto === null;
  }
  function validModelId(value) {
    return typeof value === 'string' && value.length <= 180 &&
      /^[a-zA-Z0-9][a-zA-Z0-9._/:+-]*$/.test(value) &&
      !/^(sk-|AIza|eyJ)/.test(value);
  }
  function validateValues(value) {
    if (!isRecord(value)) throw new Error('설정은 객체여야 합니다.');
    const clean = {};
    for (const key of Object.keys(value)) {
      if (!KEYS.includes(key)) throw new Error('지원하지 않는 설정 키가 있습니다.');
      const v = value[key];
      const valid = key === 'model' ? validModelId(v) : key === 'useRag' ? typeof v === 'boolean' :
        key === 'modelSelectionMode' ? ['preferred', 'strict', 'auto'].includes(v) :
          ['AUTO', 'OFF', 'FORCE_LIGHT', 'FORCE_DEEP'].includes(v);
      if (!valid) throw new Error('설정 값의 형식 또는 범위가 맞지 않습니다.');
      clean[key] = v;
    }
    return clean;
  }
  function mergeDefaults(value) {
    return Object.assign({}, DEFAULTS, validateValues(value));
  }
  function exportSettings(value) {
    return JSON.stringify({ version: 1, values: validateValues(value) }, null, 2);
  }
  function importSettings(text) {
    if (typeof text !== 'string' || text.length > MAX_BYTES ||
        new TextEncoder().encode(text).byteLength > MAX_BYTES) {
      throw new Error('설정 파일은 UTF-8 기준 16 KiB 이하여야 합니다.');
    }
    let envelope;
    try { envelope = JSON.parse(text); } catch { throw new Error('올바른 JSON 파일이 아닙니다.'); }
    if (!isRecord(envelope) || envelope.version !== 1 || !Object.hasOwn(envelope, 'values') ||
        Object.keys(envelope).some(key => !['version', 'values'].includes(key))) {
      throw new Error('지원하지 않는 설정 파일 버전 또는 구조입니다.');
    }
    return validateValues(envelope.values);
  }

  }

      }

      observer = null;
      if (timer !== null) win.clearTimeout(timer);
      timer = null;
      pending = {};

      try {
        // Presence only; never deserialize run tokens or copy them to owned storage.

          !win.sessionStorage.getItem('chat.activeRun');
      } catch { return false; }

    };

      option.value === value && !option.disabled && !option.parentElement?.disabled);

      if (!freshSession()) { stop(); message('session-preserved'); return; }
      const changed = [];

        const control = controls[key];
        if (control.disabled || (key !== 'useRag' && !selectable(control, pending[key]))) continue;
        const before = key === 'useRag' ? control.checked : control.value;
        if (key === 'useRag') control.checked = pending[key];
        else control.value = pending[key];
        if (before !== pending[key]) changed.push(control);
        delete pending[key];
      }
      // Set the whole available snapshot before synchronous change listeners run.
      applying = true;
      try {
        changed.forEach(control => control.dispatchEvent(new win.Event('change', { bubbles: true })));
      } finally { applying = false; }
      if (Object.keys(pending).length === 0) { stop(); message('applied-or-inherited'); }

      }
      timer = win.setTimeout(() => { stop(); message('pending-unavailable'); }, 8000);
      applyAvailable();
    };
    for (const [key, control] of Object.entries(controls)) {
      control.addEventListener('change', () => {
        if (!applying && Object.hasOwn(pending, key)) {
          delete pending[key];
          if (!Object.keys(pending).length) stop();
        }
      });
    }
    // Existing DOM event contract, not an internal chat.js function or global variable.
    doc.addEventListener('brain-state:session', event => {
      if (event.detail?.sessionId) { stop(); message('session-preserved'); }
      else begin();
    });
    win.addEventListener('storage', event => {
      if (event.key === STORAGE_KEY || event.key === null) {
        stop();
        message('next-new-chat'); // Never mutate an active conversation from another tab.
      }
    });

    win.addEventListener('pageshow', event => {
      // A bfcache return preserves the existing composer rather than reapplying defaults.
      if (event.persisted) message('next-new-chat');
    });
    begin();
  }
  return Object.freeze({ STORAGE_KEY, MAX_BYTES, DEFAULTS, KEYS, validModelId,
    validateValues, mergeDefaults, exportSettings, importSettings, readSettings,
    writeSettings, withoutKeys, installBridge });

  }
  function shape(value, allowed, required = []) {
    if (!record(value) || Object.keys(value).some(key => !allowed.includes(key)) ||
        required.some(key => !Object.hasOwn(value, key))) throw Error('invalid_settings_shape');
  }
  function bool(v) { if (typeof v !== 'boolean') throw Error('invalid_boolean'); return v; }
  function integer(v, min, max, zero = false) {
    if (!Number.isSafeInteger(v) || (!(zero && v === 0) && (v < min || v > max))) {
      throw Error('invalid_integer_range');
    }
    return v;
  }
  function choice(v, allowed) { if (!allowed.includes(v)) throw Error('invalid_choice'); return v; }
  function model(v) {
    if (typeof v !== 'string' || v.length > 180 || !/^[a-zA-Z0-9][a-zA-Z0-9._/:+-]*$/.test(v) ||
        /^(sk-|AIza|eyJ)/.test(v)) throw Error('invalid_model');
    return v;
  }
  function binding(value) {
    const keys = ['assistId', 'epoch', 'clientId'];
    shape(value, keys, keys);
    for (const key of ['assistId', 'clientId']) {
      // Broad client-side sanity only. Existing server ownership validation is authoritative.
      if (typeof value[key] !== 'string' || !value[key].trim() || value[key].length > 256 ||
          /[\u0000-\u001f\u007f]/.test(value[key])) throw Error('invalid_connection');
    }
    integer(value.epoch, 0, Number.MAX_SAFE_INTEGER);
    return { assistId: value.assistId, epoch: value.epoch, clientId: value.clientId };
  }
  const LENS_RANGES = Object.freeze({
    transcriptFontPx: [20, 36], hintFontPx: [20, 36], transcriptMaxLines: [1, 8], hintPageLines: [4, 13],
    transcriptTtlMs: [1000, 100000], hintTtlMs: [1000, 100000], autoPageMs: [1000, 100000, true],
    hintTargetChars: [240, 1100], historyWindowMs: [5000, 300000, true],
    historyMaxChars: [200, 8192, true], historyMaxTokens: [50, 4096, true],
    triggerQuietMs: [500, 30000], cueCooldownMs: [1000, 120000], forceAfterMs: [1000, 600000]
  });
  const LENS_KEYS = Object.freeze([...Object.keys(LENS_RANGES), 'historyEnabled', 'topicResetEnabled', 'preset']);
  function validateLensPatch(value) {
    shape(value, LENS_KEYS);
    const out = {};
    for (const key of Object.keys(value)) {
      if (value[key] === null) continue; // Existing patch null means keep the current value.
      if (Object.hasOwn(LENS_RANGES, key)) out[key] = integer(value[key], ...LENS_RANGES[key]);
      else if (key === 'preset') out[key] = choice(value[key], ['DEFAULT', 'READ_EASY', 'DENSE']);
      else out[key] = bool(value[key]);
    }
    return out;
  }
  function validateFocus(value) {
    const required = ['enabled', 'wakeWord', 'utteranceQuietMs', 'followupIdleMs', 'wakeListenTimeoutMs',
      'presentation', 'recallEnabled', 'rememberFactsEnabled'];
    shape(value, [...required, 'snapshot', 'answerSelection', 'recentContext', 'memory'], required);
    if (typeof value.wakeWord !== 'string' || !value.wakeWord.trim() ||
        [...value.wakeWord].length > 16 || /[\u0000-\u001f\u007f-\u009f]/.test(value.wakeWord)) {
      throw Error('invalid_wake_word');
    }
    const out = { enabled: bool(value.enabled), wakeWord: value.wakeWord.trim(),
      utteranceQuietMs: integer(value.utteranceQuietMs, 500, 5000),
      followupIdleMs: integer(value.followupIdleMs, 5000, 120000),
      wakeListenTimeoutMs: integer(value.wakeListenTimeoutMs, 3000, 30000),
      recallEnabled: bool(value.recallEnabled), rememberFactsEnabled: bool(value.rememberFactsEnabled) };
    const p = value.presentation;
    const pk = ['sequentialTextEnabled', 'charIntervalMs', 'maxVisibleLines', 'autoFadeEnabled', 'tailHoldMs', 'fadeMs'];
    shape(p, pk, pk);
    out.presentation = { sequentialTextEnabled: bool(p.sequentialTextEnabled),
      charIntervalMs: integer(p.charIntervalMs, 50, 160), maxVisibleLines: integer(p.maxVisibleLines, 4, 8),
      autoFadeEnabled: bool(p.autoFadeEnabled), tailHoldMs: integer(p.tailHoldMs, 2000, 15000),
      fadeMs: integer(p.fadeMs, 200, 1000) };
    if (value.snapshot != null) {
      shape(value.snapshot, ['enabled', 'source'], ['enabled', 'source']);
      out.snapshot = { enabled: bool(value.snapshot.enabled),
        source: choice(value.snapshot.source, ['FOLD_REAR', 'META_GLASSES']) };
    }
    if (value.answerSelection != null) {
      const a = value.answerSelection;
      shape(a, ['mode', 'modelId', 'routing'], ['mode']);
      out.answerSelection = { mode: choice(a.mode, ['AUTO', 'FIXED']), modelId: a.mode === 'AUTO' ? null : model(a.modelId) };
      if (a.routing != null) {
        const r = a.routing;
        shape(r, ['executionTarget', 'fallbackAllowed', 'allowedFallbackIds'], ['executionTarget', 'fallbackAllowed']);
        const ids = r.allowedFallbackIds ?? [];
        if (!Array.isArray(ids) || ids.length > 3) throw Error('invalid_fallback_ids');
        out.answerSelection.routing = { executionTarget: choice(r.executionTarget, ['AUTO', 'API_ONLY', 'LOCAL_ONLY']),
          fallbackAllowed: bool(r.fallbackAllowed), allowedFallbackIds: [...new Set(ids.map(model))] };
      }
    }
    if (value.recentContext != null) {
      const r = value.recentContext;
      const keys = ['enabled', 'maxAgeSeconds', 'maxUtterances', 'tokenBudget'];
      shape(r, keys, keys);
      out.recentContext = { enabled: bool(r.enabled), maxAgeSeconds: integer(r.maxAgeSeconds, 30, 180),
        maxUtterances: integer(r.maxUtterances, 1, 12), tokenBudget: integer(r.tokenBudget, 256, 2000) };
    }
    if (value.memory != null) {
      const m = value.memory;
      shape(m, ['mode', 'graphMode', 'maxEvidence', 'embeddingPrefer', 'webOnUnknown']);
      out.memory = { mode: m.mode == null ? null : choice(m.mode, ['OFF', 'RECALL', 'FULL']),
        graphMode: choice(m.graphMode ?? 'OFF', ['OFF', 'AUTO', 'ON']),
        maxEvidence: integer(m.maxEvidence ?? 4, 1, 8),
        embeddingPrefer: choice(m.embeddingPrefer ?? 'LOCAL_THEN_CLOUD', ['LOCAL_ONLY', 'LOCAL_THEN_CLOUD', 'CLOUD_ONLY']),
        webOnUnknown: m.webOnUnknown == null ? null : bool(m.webOnUnknown) };
    }
    // Explicit null optional blocks are preserved; omitted blocks remain omitted.
    for (const key of ['snapshot', 'answerSelection', 'recentContext', 'memory']) {
      if (Object.hasOwn(value, key) && value[key] === null) out[key] = null;
    }
    return out;
  }
  function validateRelay(value) {
    shape(value, ['enabled', 'segmentSeconds'], ['enabled', 'segmentSeconds']);
    return { enabled: bool(value.enabled), segmentSeconds: integer(value.segmentSeconds, 5, 60, true) };
  }
  function makeRequest(kind, connection, input = {}) {
    const body = binding(connection);
    let path;
    switch (kind) {
      case 'focus-read':
        shape(input, []);
        path = '/api/assist/display/focus/settings/read';
        break;
      case 'focus-save':
        shape(input, ['settingsVersion', 'settings'], ['settingsVersion', 'settings']);
        body.settingsVersion = integer(input.settingsVersion, 0, Number.MAX_SAFE_INTEGER);
        body.settings = validateFocus(input.settings);
        path = '/api/assist/display/focus/settings';
        break;
      case 'relay-save':
        Object.assign(body, validateRelay(input));
        path = '/api/assist/display/relay/settings';
        break;
      case 'lens-save':
        body.display = validateLensPatch(input);
        if (!Object.keys(body.display).length) throw Error('empty_patch');
        path = '/api/assist/display/relay/lens-settings';
        break;
      case 'lens-reset':
        shape(input, []);
        body.restoreDefaults = true;
        path = '/api/assist/display/relay/lens-settings';
        break;
      default: throw Error('unsupported_settings_operation');
    }
    return { path, method: 'POST', body };
  }
  function pickSettingsResponse(kind, data) {
    if (!record(data)) throw Error('invalid_settings_response');
    if (kind.startsWith('focus-')) {
      return { settingsVersion: integer(data.settingsVersion, 0, Number.MAX_SAFE_INTEGER),
        settings: validateFocus(data.settings) };
    }
    // Discard transcripts, cards, Jev details, owner identifiers and all other View fields.
    if (kind === 'relay-save') {
      const r = data.testStatus?.relay;
      return validateRelay({ enabled: r?.enabled, segmentSeconds: r?.segmentSeconds });
    }
    const lens = data.testStatus?.lensDisplay;
    if (!record(lens)) throw Error('invalid_lens_response');
    const selected = {};
    for (const key of LENS_KEYS.filter(key => key !== 'preset')) {
      if (!Object.hasOwn(lens, key)) throw Error('incomplete_lens_response');
      selected[key] = lens[key];
    }
    return validateLensPatch(selected);
  }
  async function request(kind, connection, input = {}, options = {}) {
    const spec = makeRequest(kind, connection, input);
    const fetchFn = options.fetchFn || globalThis.fetch.bind(globalThis);
    const controller = new AbortController();
    const abort = () => controller.abort();
    if (options.signal?.aborted) controller.abort();
    options.signal?.addEventListener('abort', abort, { once: true });
    const timer = setTimeout(abort, 8000);
    try {
      const response = await fetchFn(spec.path, { method: spec.method, credentials: 'same-origin',
        cache: 'no-store', redirect: 'error', headers: { 'Content-Type': 'application/json', 'Accept': 'application/json' },
        body: JSON.stringify(spec.body), signal: controller.signal });
      if (!response.ok || response.redirected || !(response.headers.get('content-type') || '').includes('application/json')) {
        const error = Error('display_settings_request_failed');
        error.status = response.status;
        throw error;
      }
      return pickSettingsResponse(kind, await response.json());
    } finally {
      clearTimeout(timer);
      options.signal?.removeEventListener('abort', abort);
    }
    // No automatic retry. A failed/aborted write may already have committed.
  }
  return Object.freeze({ makeRequest, request, validateFocus, validateLensPatch, pickSettingsResponse });
});
```

## 4. 기존 파일 최소 수정안

### 4.1 `chat-ui.html` unified diff — 파일 전체 기준 10줄

### 4.2 보안 변경 필요성 — diff가 아닌 별도 제안

**기본 제공안의 보안 변경은 0이다.** 다만 “일반 모드에서도 익명 `/settings`가 `/chat`처럼 공개”라는 추가 완료 조건은 현재 `AppSecurityConfig.java:180–203`와 양립하지 않는다. 그 조건까지 만족시키려면 기존 public 페이지 allowlist에 **정확히 `/settings` 한 경로만** 추가하는 최소안이 필요하다. 이는 새 페이지 접근만 공개하며 `/api/settings/**`, `/model-settings/**`, ROLE_ADMIN, AdminTokenGuard, 마스킹, 기존 CSRF 계약은 그대로 둔다는 안이다.

이 최소안을 이번 patch에 몰래 넣지 않는다. 새 SecurityFilterChain, `/settings/**` 광범위 공개, `/** permitAll`, AdminTokenGuard 제외, PROTO_OPEN 강제 활성화로 우회하지 마라. 사용자 요구의 우선순위를 확인하지 않은 상태에서 모두 완료했다고 보고하지 마라. PROTO_OPEN을 켜거나 끄는 작업 자체도 이번 범위 밖이다.

SYSTEM_PROMPT 공개 allowlist 변경, OPENAI_MODEL 민감 키 예외, Display 새 세션/권한 인계 API는 각각 별도 계약 검토가 필요하다. 이를 “설정 페이지를 위해 필요한 작은 수정”이라고 묶지 않는다.

### 6.1 적용 순서와 targeted 확인 명령

git apply --reverse .\patches\chat-ui.patch
```

이번 작업에서 추가한 파일만 식별해 제거하거나 해당 변경 commit만 되돌린다. `git reset --hard`, `git clean -fd`, src 전체 복사, DB 전체 복원은 사용하지 않는다. 신규 namespace는 남겨도 기존 코드가 소비하지 않으므로 다른 브라우저 설정과 충돌하지 않는다. 완전 제거가 필요한 사용자의 명시적 동의가 있으면 **이 키 하나**만 제거한다.

```javascript
localStorage.removeItem('awx.settings.v1.preferences');
```

코드 rollback은 관리자가 이미 저장한 서버 공통 설정을 자동 취소하지 않는다. API 검증 중 수정한 서버 값은 사전에 기록한 해당 키만 기존 API로 복귀시킨다. 원래 DB override가 없던 키를 새로 저장했다면 현 API에는 삭제 계약이 없어 “원래 상속 상태” 복원은 단순 POST로 동일하지 않다. 따라서 disposable test DB 또는 기존 override가 명확한 키로 먼저 검증해야 한다. Display 어댑터는 기본 UI에서 호출하지 않았으므로 기본 적용만으로 생기는 Display 데이터 rollback은 없다.

### 6.4 요청 완료 기준 매핑

C1: 인벤토리 108행과 요청 API 전체를 수록했고 각 행은 source 위치 또는 제안 표시가 있다. 다만 범위 밖 모든 환경변수를 사용자 설정으로 전수 목록화했다는 주장은 하지 않는다.  
C2: 요청한 새 파일 5개와 선택 Display 어댑터의 전체 소스를 이 문서와 개별 파일에 모두 제공한다. 생략된 함수 본문은 없다.  
C3: 원본 chat.js/스키마/보안/API 변경 0. 일반 모드 공개 경로 충돌은 보안 diff 대신 최소 제안만 기록했다.  
C4: chat-ui patch는 10줄, 실제 삽입 2줄. bridge의 getElementById 대상은 지정 네 ID뿐이다. 브리지 자체의 namespace와 기존 DOM 이벤트만 사용하며 chat.js 전역/내부 함수를 호출하지 않는다.  
C5: Node 테스트 파일 1개 + MockMvc 클래스 1개 + targeted 적용/복귀 체크리스트를 제공했다. MockMvc는 **초안 제공**이지 실행 통과가 아니다.

## 7. 추가로 필요한 파일·정보와 외부 참고 근거

### 7.1 실제 누락 파일

|필요 자료|이유|현재 처리|
|---|---|---|
|프로젝트 루트 build.gradle 또는 build.gradle.kts, settings.gradle, gradle.properties, wrapper properties/jar/scripts|Java/Boot/Gradle 실제 버전, sourceSets, test dependency, module root 확인|버전과 적용 루트를 요청서의 가정으로만 표기. Spring 실행 미주장.|
|현재 src/test 전체 중 보안 체인·Thymeleaf·chat 관련 fixture/테스트|실제 filter chain·AOP·템플릿 통합 테스트와 충돌 없이 targeted 검증|테스트 이름을 임의로 만들지 않고 독립 DraftTest만 제공.|
|현재 적용 checkout의 변경 상태/소스 기준 commit 및 루트 경로|FIND_X 스냅샷과 실제 Codex 작업 트리의 차이 확인|ZIP SHA/개별 파일 해시를 기준으로 비교하도록 지시.|

`chat.js`, PageController, 보안 체인, Display controller/settings records, 기존 display-conversate.js/app.js는 **FIND_X 안에서 확인했다**. 본문 16개 파일 설명처럼 누락됐다고 다시 요청하지 않는다. 스튜디오 코드는 추가 요청 대상도 아니다.

### 7.2 파일보다 먼저 확정해야 하는 실행 정보

현재 사용 profile의 PROTO_OPEN·demo.interview.enabled·두 conversate feature flag 활성 여부가 필요하다. 비밀값 자체는 필요 없다. 일반 모드 익명 /settings 공개와 보안 0변경 중 우선 조건도 현재 소스에서는 동시에 만족할 수 없다. Display는 현재 수음 producer를 유지하는 페이지 간 인계 방식과 owner/channel의 생명주기 범위를 먼저 정해야 한다. 자동 bootstrap이나 token 복제로 대신할 수 없다.

실제 서버 API의 안전한 샘플이 있다면 설정 6키와 응답 status/header 정도로 최소화해 확인한다. cookie/Authorization/API key, SYSTEM_PROMPT, 대화 본문, Display 카드·전사·연결 토큰은 수집·첨부하지 않는다. 공개 운영 서버의 값을 이 작업에서 직접 변경하지 않았다.

### 7.3 외부 공식 문서 — 참고 이유와 URL

외부 자료는 웹 API와 테스트 기법 확인에만 사용했다. 첨부 소스의 동작을 웹 자료로 대신 판정하지 않았다. 문서 기준 확인일은 2026-10-01이다. 현재 Node 공식 문서의 표시 버전은 프로젝트 버전 증거가 아니며, 새 런타임 업그레이드를 지시하지 않는다.

### 7.4 패키지 읽는 순서

이 문서 1–2절로 실제 계약과 막힌 조건을 확인하고, 3–4절의 새 파일/patch를 적용 후보로 검토한다. 5절의 두 테스트와 6절의 단계별 명령으로 검증하고, 미충족 기능은 7절의 필요한 정보와 함께 별도로 남긴다. Node 로그나 patch-check 성공만으로 전체 기능을 녹색 처리하지 않는다.

**최종 상태:** 소스 근거에 맞춘 설정 페이지 설계·소스 초안·최소 patch·테스트 초안 제공. 실제 프로젝트에 대한 구현·통합·배포 완료 선언은 하지 않는다.
