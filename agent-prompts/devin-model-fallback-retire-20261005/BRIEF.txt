  - `BAD_REQUEST`는 폴백 대상이 아니어서 모델 단종 에러가 그대로 사용자 에러로 전파됨.

### 3. 작업 항목

#### DV01: `LlmGatewayFailureClassifier.java` 단종·퇴역 에러 패턴 분류 확장
- 위치: `main/java/com/example/lms/llm/gateway/LlmGatewayFailureClassifier.java`
- 작업 내용:
  1. `classifyMessage(String message)` 내에 모델 단종/퇴역 관련 시그니처 추가:
     - `deprecated`, `decommissioned`, `retired`, `no longer supported`, `not supported for api version`, `model_not_found`, `model not found` 탐지 시 `LlmFailureClass.MODEL_MISSING` 반환.
  2. `classifyHttpStatus(int status, String responseText)`:
     - HTTP 404 외에 HTTP 400 및 410에서 `responseText`를 검사하여 모델 단종 키워드나 에러 코드(`model_deprecated`, `model_not_found`)가 포함된 경우 `LlmFailureClass.MODEL_MISSING`으로 분류되도록 보장.
     - 기존 Quota 및 ChatGPT OAuth 에러코드 검사 순서와 격리 유지.

#### DV02: `FallbackAwareChatModel.java`에 `MODEL_MISSING` 폴백 허용 추가
- 위치: `main/java/com/example/lms/llm/gateway/FallbackAwareChatModel.java`
- 작업 내용:
  1. `fallbackAllowed(Throwable failure, LlmFailureClass failureClass)` (라인 ~415):
     - `apiFirstPolicy` 블록의 허용 집합에 `LlmFailureClass.MODEL_MISSING` 추가.
  2. `sameRequestFallbackAllowed(Throwable failure, LlmFailureClass failureClass)` (라인 ~529):
     - 비 API 우선/로컬 경로에서도 모델이 없을 경우 재생 가능한 경우에 한해 폴백이 가능하도록 `LlmFailureClass.MODEL_MISSING` 추가.
  3. `doChat`의 로그 및 TraceStore 기록에서 `llm.gateway.fallbackReason`에 `model_unavailable` 또는 `model_missing`이 명확히 남도록 보존.

#### DV03: 단종 모델 대응 자동 폴백 경로 체인 우선순위 보장
- 위치: `FallbackAwareChatModel.java` 및 관련 라우팅 정책
- 작업 내용:
  1. `MODEL_MISSING`으로 인한 장애조치 발생 시 NextFallbackResolver가 다음 순위의 안정적 모델을 선택하도록 연계:
     - ChatGPT OAuth 경로: 비정상/단종 슬러그(`gpt-reserve`, `gpt-5.6-sol`, `gpt-5.6-terra` 등) 실패 시 -> 안정 슬러그 `gpt-5.5` 또는 `gpt-5.6-luna`로 전이. OAuth 전체 불능 시 API 모델(`gemini-3.8-flash` 등)로 안전 탈출.
     - Gemini API 경로: `gemini-2.5-pro` 실패 시 -> 최신 안정 `gemini-3.8-flash` (또는 `gemini-3.5-flash-lite`)로 전이.
     - OpenAI API 경로: `gpt-4.1` / `gpt-4o-mini` 실패 시 -> `gpt-5.4-mini` / `gpt-5.5`로 전이.
  2. 이미 시도한 경로(`usedRoutes`) 재진입 방지 및 최대 fallback 횟수(`maxFallbackCalls`, 기본 1~3회) 준수.
