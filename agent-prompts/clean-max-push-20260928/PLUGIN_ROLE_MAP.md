# Stuff4 role map for MAX-PUSH

Contract: `DEMO1-CLEAN-MAX-PUSH-DYNAMIC-RAIL-20260928`

The original Stuff4 list (Browser admin scenarios, a whole-suite gate, and the
other plugins) was written for a security and auth session. This table is the
MAX-PUSH reading. When the original text conflicts with this table, this table
wins.

| Plugin | Use on MAX-PUSH | Do not do |
|---|---|---|
| Superpowers | systematic-debugging for one cause, RED test first. verification-before-completion is a focused suite only. | Treat a full suite as Done. Add a duplicate service or a new layer. |
| Browser | Only when Codex or the user names it. Default for MAX-PUSH is NOT_RUN. If needed, `/chat` HTTP 200 and a reasonCode only. | Count five admin-login scenarios as Done. Commit cookies or session material. Turn PROTO_OPEN off or harden admin. |
| GitHub | Read-only compare of local HEAD and the remote SHA, plus diff. | commit, push, merge, or branch delete. Any use of AbandonWare3. |
| Exa | Official docs only (Spring, executors, Neo4j Java driver) when an F0x item needs them. | Port a blog post into the Java 17 tree. |
| AWX Control Tower | `tools/build_error_miner.py scan` on a compile, test, or boot failure log. | Recovery AWX while the stack is healthy. A classification used as a patch. |
| Computer | Local console only when localhost UI cannot be read another way. | Source search or source edit through Computer. |
| glm_worker | Counter-review after Codex's first patch. Template: `GLM_COUNTERPROMPT.md`. | Treat glm agreement as GREEN. |
| Vercel | Only for a Jev or Gateway question. Default OFF. | Print key material, deploy, or commit env files. |
| Meta Wearables, Sites, Data, Visualize, Supabase, Plugin Mgmt | Unused on this queue unless the user asks. | Count glasses end-to-end as MAX-PUSH Done. |

PROTO_OPEN stays. Secret output, push, `add -A`, and turning CSRF off stay hard stops.
The vibe auth-relax rule is unchanged: admin login is not a Done item.
