# glm_worker counter-prompt (Kit C)

Use only after Codex has a first patch and a focused test command.
glm agreement is not GREEN. Ask for counterexamples, not a rewrite.

```text
Review this one MAX-PUSH patch. Do not agree by default.
Pick three failure cases from this list that fit the patch:
a cancelled call that still runs, a late source revision, an owner or consent
change, a partial batch success, a completion-order change, a duplicate retry.
Say whether ordered document identity, fence scope, or a numeric meaning changed.
Name the file and the check that would fail. Do not propose a new layer.
Do not treat a JDK probe exit code as an application pass.
```

DPP numeric meaning stays the current greedy order. A faster matrix step that
reverses two documents is a failed patch even if the probe median dropped.
