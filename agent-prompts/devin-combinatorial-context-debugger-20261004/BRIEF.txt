     - (5) `runtime_vars`: 테스트 인자/런타임 변수 (800자 이하)

  2. 무작위/휴리스틱 조합 탐침 팩 생성 (`bundle`):
     - Bundle-A (Runtime Trace): error_core + diff_trigger + runtime_vars (< 2.5KB)
     - Bundle-B (Static Contract): error_core + target_signature + config_state (< 2.5KB)
     - Bundle-C (Regression Safe): error_core + diff_trigger + config_state + precedent_pattern (< 3.0KB)
