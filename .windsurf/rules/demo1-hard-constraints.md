- Before starting work or judging deadlines and added scope, READ the shared [guard-deadline-scope](../../docs/agents-rules/DEMO1-DEADLINE-SCOPE-JUDGMENT.md) body.
  Planning margin covers the whole task; preserve existing authority, verification, and the user hard cap.

- Minimal diff. Do not delete unrelated code. No secret values in logs/commits (env names only).

- Git: working tree + active sourceSets + passing compile/test/runtime remain the baseline; old HEAD is never a restore source; a clean tree is never a completion condition; do not start ordinary work with git status/history/branch checks. Conditional local Git per AGENTS.md `DEMO1-GIT-LOCAL-FIRST` and `.grok/rules/demo1-conditional-local-git.md` (enforced by `scripts/conditional_local_git.py`): `git status`/`diff`, selective `git add` of owned paths, a staged-blob secret scan, and one local commit after that scan passes are allowed; push/pull/fetch/merge/rebase/reset/clean/history rewrite, `add -A`/`add .`/`commit -a`/`--no-verify`, taking or unstaging foreign staged paths, committing secrets/conversations/DB/models/large logs, and deleting `.git`/`index.lock` stay forbidden.
