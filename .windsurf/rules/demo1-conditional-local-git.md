- Policy body: `.grok/rules/demo1-conditional-local-git.md`; Codex-facing copy: `AGENTS.md` `DEMO1-GIT-LOCAL-FIRST`. Entry skills: `$demo1-conditional-local-git`, `$demo1-git-secret-guard`, `$demo1-git-vibe-workflow`. Do not copy the policy body here.
- Still forbidden: push/pull/fetch/merge/rebase/reset/clean/stash/init/remote/history rewrite, `git tag`/annotated tags, VERSION/CHANGELOG/RELEASE root files, semver bumps, `gh release`, versioned artifact uploads, `--amend`/`--no-verify`, `add -A`/`add .`/`commit -a`, taking another session's staged paths, committing secrets/raw conversation/databases/models/indexes/large logs, deleting `.git` or `index.lock`, killing `git.exe`. Agents make local selective commits only — never a version/release structure. The one conditional exception: a proven-stale 0-byte `index.lock` (no confirmed `git.exe` writer, unchanged index hash; `lock` default `--days` 1.0, orchestrator `--stale-lock-days` default 0.25 = 6h) is moved aside by `python -B scripts/conditional_local_git.py lock --repo . --backup-dir data/agent-handoff/<taskId>` or inside `agent_git_vibe_commit.py` — manual deletion stays forbidden and any unmet condition preserves it (BLOCKED, no question card).
- Sole valid main remote: `AbandonWareAi` (`https://github.com/UnlimitedAbandonWare/AbandonWareAi`) — the only valid remote is `origin` at that URL; report a leftover `origin` pointing anywhere else, never fetch/push to another remote, never add a second remote, and never mutate remotes without an explicit user ask (AGENTS.md `DEMO1-GIT-REMOTE-SOLE`). The gate hard-fails `scan`/`commit` (`forbidden-remote`/`origin-mismatch`, non-zero) while a non-`origin` remote or a mismatched `origin` is present.
