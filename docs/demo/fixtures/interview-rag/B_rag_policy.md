# AWX 데모 자료의 근거 정책

문서 식별자: AWX-CANARY-B-20261002. 실제 운영 정책이 아닌 합성 문서 질의용 자료다.

이 자료가 설명하는 가상 프로젝트의 정책은 다음과 같다. **근거 점수가 0.42 미만인 청크는 답변에 쓰지 않는다. 인용은 최소 2개**다. 질문이 이 가상 정책을 묻는 경우 숫자와 인용 기준을 문서에 적힌 그대로 답한다.

이 문장의 숫자는 서버의 검색 임계값을 바꾸라는 지시가 아니다. 코드, YAML, DB, 모델 라우팅 값을 이 문서 때문에 변경하지 않는다. 합성 fixture의 내용과 애플리케이션 정책을 구분한다.

근거가 없는 예산 질문에는 숫자를 만들지 않는다. 현재 문서와 오래된 메모가 충돌하면 문서의 날짜와 폐기 표시를 함께 확인한다. 첫 시연일과 현재 코드명은 A_project_codename.md의 확정 기록에 있다.

질의 시연에서는 답변 내용과 실제 화면의 근거 파일을 각각 확인한다. 요청 성공이나 스트림 시작만으로 문서가 사용되었다고 판단하지 않는다. 다시 실행할 때 같은 문서를 사용하고 결과의 키워드, 근거 표지, 오류 여부를 검사한다.
