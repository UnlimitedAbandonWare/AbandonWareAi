# A4 — 룰 fragment 제안

`AGENTS.md`에 붙이지 않았다. 통덮어쓰기 금지. 다른 세션이 그 파일을 잡고 있을 수 있으므로, 채택은 별도 명시 작업이다.

아래 블록을 그대로 붙일 후보로만 둔다.

```text
<!-- BEGIN DEMO1-ATT-CTX-TIME-LAYERS -->
## ATT / CTX 시간 층위와 증거 층위
- 일반 짧은 대화는 첫 유효 답변 또는 정직한 종료 5초, 전체 30초를 유지한다. 첨부가 있다는 이유만으로 이 예산을 180/240/300초로 올리지 않는다.
- 이미 승인된 첨부 분석 job만 기존 약 300초 상한 안에서 부모 deadline의 남은 시간만 쓴다. 300초를 한 번 더 더하지 않는다. chat 실행이 만료된 뒤 이름만 바꾼 job으로 계속하지 않는다.
- 웹 검색·RAG·긴 도구 루프의 벽시계는 일반 chat 5초/30초와 다른 층이다. 그 층이 약 5분이더라도 SCOPED_RAG, RECENT_ONLY, 요청 OFF의 검색 범위를 웹으로 넓히지 않는다.
- 과거 완료 보고, PROJECT_STATUS 행, 영상 메모는 live 증거가 아니다. 파일 해시와 이번 실행의 명령·exit가 있을 때만 현재 구현으로 적는다.
- 보고서 본문의 `소스파일:L100`은 문서가 주장한 위치다. ZIP 또는 live 소스의 같은 해시·심볼과 맞을 때만 확인된 소스 위치다. 보고서 L100과 소스 L100을 같은 줄로 적지 않는다.
- 테스트 0건, dry-run, 전체 suite의 무관한 실패 수선을 Done으로 적지 않는다. soft-only 설정을 무한 대기의 면제 조항으로 적지 않는다.
<!-- END DEMO1-ATT-CTX-TIME-LAYERS -->
```

## 지울 것을 제안하는 문장

제품 설정이나 `AGENTS.md`에서 아래 취지가 보이면 삭제 후보다 위 fragment가 우선한다고 제안한다. 이번 세션은 그 문장을 찾아 지우지 않았다.

- 일반 chat에 300초를 추가해도 된다는 문장.
- soft-only이면 타임아웃 없이 기다려도 된다는 문장.
- 전체 suite가 녹색이어야 ATT 또는 CTX가 끝났다는 문장.
- admin 로그인이나 HOLD Browser 장면을 기능 완료로 세는 문장.

`application-llm.yaml`의 `max-time-budget-ms`는 이번 세션에서 다시 열지 않았다. 예전 PROJECT_STATUS 행이 300000이라고 적혀 있어도, 그 행은 이 fragment의 live 근거가 아니다. Codex가 공유 YAML을 열기 전에 현재 값을 다시 읽는다. 조수는 그 값을 올리지 않는다.
