# demo-1 종합 현황 (PROJECT_STATUS)

이 문서는 이 체크아웃의 **유일한 대표 현황 진입점**이다. 새 에이전트는 작업 시작 시
여기부터 읽고, 그 다음 `python -B scripts/work_journal.py list --active`와
자기 작업 범위의 실제 파일을 확인한다. 전체 소스와 과거 보고서를 매번 다시 읽지 않는다.

- 절차 원본: `.agents/skills/demo1-work-ledger/SKILL.md`
- 작업 등록/기록: `scripts/work_journal.py` → `data/agent-handoff/codex-autonomy/<taskId>/journal.json`
- 변경 전 보존/복구: `scripts/codex_work_checkpoint.py` (`docs/codex-autonomous-work.md`)
- 소스 동시수정: `__patch_drop__/source_edit_session.ps1` + `scripts/guarded_source_edit.js`

> 상태 표기 규칙: `source`(소스에 구현됨) / `built`(빌드 결과 포함 확인) /
> `running`(실행 중 서비스 반영 확인) / `onGlasses`(실제 안경 확인) /
> `unverified`(미검증) / `failed`(실패 관찰) / `stale`(관련 파일 변경 후 재검증 필요).
> 문서 저장 시각(docSavedAt)과 실제 파일·동작 확인 시각(evidenceCheckedAt)을 구분한다.
> 소스가 바뀐 항목의 과거 검증 결과를 현재 상태의 보증으로 재사용하지 않는다.

## 1. 프로젝트 목적과 주요 기능

- Java 17 + Spring Boot(Gradle) **Dynamic RAG Orchestration Platform**: 전사(Conversate/ASR)
  → 검색/검색보강 → LLM 힌트 생성 → Meta Ray-Ban Display 렌즈 표시.
- 로컬 우선(올라마/로컬 임베딩), 유료 API는 라우팅 정책(`configs/api-routing.yaml`,
  `docs/API_ROUTING_SPEC.md`)과 spend guard 하에서만.
- 익명 사용 기본: `demo.interview.enabled=true`일 때 `/`,`/index`,`/chat-ui` →
  `/assets/interview/index.html`, RAG 클라이언트는 `/api/chat/sync`.
